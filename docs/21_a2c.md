# 21. A2C：同步优势 Actor-Critic

A2C（Advantage Actor-Critic）是同步版本的优势 Actor-Critic。它使用策略网络采样动作、价值头估计状态价值，并用一批 on-policy rollout 同步更新参数。与 PPO 相比，A2C 不使用 importance ratio clipping；实现更直接，但对学习率、rollout 长度和优势方差更敏感。

## 1. Return 与 Advantage

给定 rollout 的奖励 (r_t)、终止标志 (d_t)，以及最后一个状态的 bootstrap value (V(s_T))，折扣回报递推为：

[
G_t=r_t+gamma(1-d_t)G_{t+1},quad G_T=V(s_T).
]

优势估计为：

[
A_t=G_t-V_phi(s_t).
]

如果环境因为 time limit 截断，最后状态仍应 bootstrap，因此传入的 done mask 应表示真正的 MDP termination，而不是把 terminated 与 truncated 简单合并。

## 2. Actor 与 Critic 损失

策略损失：

[
mathcal L_pi=-mathbb E_t[logpi_	heta(a_t|s_t)operatorname{sg}(A_t)].
]

价值损失：

[
mathcal L_V=mathbb E_t[(V_phi(s_t)-G_t)^2].
]

熵正则鼓励探索：

[
mathcal L=mathcal L_pi+c_Vmathcal L_V-c_Hmathbb E_t[H(pi_	heta(cdot|s_t))].
]

其中 (operatorname{sg}) 表示 stop-gradient，避免 actor policy loss 通过 advantage 反向修改 critic。

## 3. 训练接口

`A2CAgent.update(states, actions, returns)` 更新一批 rollout。采集循环由调用方负责：先用当前策略与环境交互，收集 states/actions/rewards/terminated，计算最后状态 bootstrap，再调用 `discounted_returns` 和 `update`。这是单进程同步基线，不包含异步 actor、并行环境管理或向量化 rollout worker。
