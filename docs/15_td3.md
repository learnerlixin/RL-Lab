# 15. TD3：Twin Delayed DDPG

TD3 是连续动作、off-policy actor-critic 方法，针对 DDPG 的 Q 过估计和策略更新不稳定提出三个技巧：

1. **Clipped Double Q**：两个 critic 取较小值构造 target。
2. **Delayed Policy Update**：critic 每步更新，actor 与 target 网络隔若干步更新。
3. **Target Policy Smoothing**：target action 加入裁剪后的噪声，平滑 Q 对动作的尖锐估计。

目标：
\[
y=r+\gamma(1-d)\min_{i=1,2}
Q_{\bar\phi_i}(s',\operatorname{clip}(\mu_{\bar\theta}(s')+\epsilon)).
\]
Actor 最大化 \(Q_1(s,\mu_\theta(s))\)。实现使用连续动作 replay buffer，可与 SAC 共用数据接口。
